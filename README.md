# dominating_set
PACE 2025 challenge on dominating set made in an Academic course

## Install
Download archive or clone


Go to folder
```
mkdir build 
cd build
cmake ..
make
```

## Run

```
dom_set_main -h
```
for help
Available algorithms are heap,bucket,genetic,wgenetic,milp,sat
Input files in folder data constituted of instances of FVS PACE Challenge and test instances for the 2025 PACE challenge on dominating set
## Benchmark

run script benchmark.py and specify algorithm.
Specifying output folder is recommended
